# 스탠다리아: 국경의 수호자 (Standaria)

> **기술규제를 외우는 대신, 판단하게 만드는 게임**
>
> 해외기술규제와 적합성평가 지식을 **자료 조사 → 근거 선택 → 전략 판단 → 결과 피드백**의 과정으로 학습하도록 설계한 Android 교육용 RPG입니다.

**현재 상태:** 개발·테스트 단계의 개인 프로젝트 · **소스 버전 0.1.4** · Google Play **내부/비공개 테스트** 진행 · **일반 공개 출시 전**

- **플랫폼:** Android 8.0 이상(API 26+) / 세로형 / 오프라인 WebView 앱
- **패키지:** `kr.cau.regulaguild`
- **기술:** HTML · CSS · JavaScript · Java · Android SDK · Kontra.js · Git/GitHub
- **개발 방식:** 기획자가 게임 목표·학습 콘텐츠·규칙·UX 요구사항을 정의하고, **AI와 협업해 구현한 뒤 직접 실행·검수·개선**하는 방식
- **프로젝트 시작:** 2026년 10월

## 왜 만들었나

해외기술규제 실무에서는 표준과 기술규정의 의무성, 시험·인증·인정의 차이, 국가별 시장진입 조건 등을 **상황에 맞춰 판단**해야 합니다. 단순히 용어를 암기하는 학습에서 벗어나, 제한된 예산·기간·신뢰를 고려하며 근거를 선별하는 학습 경험을 만들고자 했습니다.

**설계 원칙:** 캐릭터 능력치나 장비가 틀린 판단을 정답으로 바꾸지 않습니다. 올바른 근거와 전략을 선택했을 때에만 RPG 성장 요소가 그 효과를 높입니다.

## 게임 콘텐츠와 핵심 루프

| 콘텐츠 | 구현 범위 |
|---|---|
| 학습 거점 | **6개** 지역과 탐험 지도·NPC |
| 의뢰·판단 | **13개** 연속 의뢰, **39개** 학습 자료, **26개** 전략 판단 단계 |
| 캐릭터 성장 | **3개** 직업, **5개** 전문역량 능력치, **7개** 장비, **3개** 스킬 |
| 선택형 이벤트 | **3개** 가상 국제 정세 사건과 이해관계자별 협력 지수 |
| 학습 지원 | 근거 해설, 공식 출처·기관 관계 도감, 완료 의뢰 복습 |
| 기록 관리 | 기기 내 자동 저장, JSON 백업/복원, 텍스트 학습 보고서 |

**플레이 흐름**

1. 길드 의뢰를 수락하고 상황과 목표를 확인합니다.
2. 자료 3개를 검토해 핵심 증거 2개를 선택합니다.
3. 두 단계의 대응 전략을 결정합니다.
4. 예산·기간·신뢰에 대한 결과와 해설을 확인합니다.
5. 성공 시 성장 보상을 받고 다음 지역·의뢰를 해금합니다. 실패하면 피드백을 바탕으로 재도전합니다.

의뢰에서는 기술규정의 의무성·전환기간, 시험·인증·인정, EU CE, 미국 NRTL, WTO TBT 통보·의견제출 등을 다룹니다. 최종 의뢰는 복수 시장에 진출하는 가상 스마트글래스 시나리오를 종합적으로 검토합니다.

## 기획과 개발에서 담당한 일

- **문제 정의·기획:** 교육 목표와 전문역량 선정, 세계관·퀘스트 및 학습 흐름 설계
- **AI 협업:** 기능별 요구사항을 제시하고 AI가 생성·수정한 코드 및 콘텐츠의 동작을 검토
- **UX 개선:** Galaxy 기기의 시스템 상태바·하단 내비게이션과 게임 조작 영역이 겹치는 문제를 발견하고, Android `WindowInsets` 기반의 WebView 레이아웃 개선을 요구·검수
- **QA·배포 관리:** 설치 및 기능 점검, GitHub 버전 관리, Google Play Console 내부·비공개 테스트 절차 진행

**역할의 범위:** 모든 소스코드를 처음부터 수작업으로 작성한 프로젝트가 아닙니다. 전문지식의 콘텐츠화, 요구사항 정의, 오류 재현·개선 방향 판단, 결과 검수와 배포 관리를 중심으로 수행한 **AI 협업 개발 프로젝트**입니다.

### 소스 빌드

요구 환경: **JDK 17+**, Android SDK **platform android-36**, **build-tools 35.0.0**.

```bash
git clone https://github.com/seongkeun316-star/regula-guild.git
cd regula-guild
export ANDROID_SDK_ROOT=/your/android-sdk
./build-apk.sh
```

로컬 출력 경로는 `build/Standaria-0.1.4.apk`입니다. 스크립트는 테스트용 개발 서명키를 로컬에서 생성·사용하므로 **Google Play 배포 서명과 동일하지 않습니다**. 앱 업데이트 가능 여부는 서명키와 설치 경로에 따라 달라집니다. Gradle 프로젝트도 제공되지만 wrapper는 포함되어 있지 않습니다.

## 테스트 범위 및 한계

- `tests/game.test.cjs`: 13개 의뢰, 해금, 중복 보상 방지, 능력치·장비·스킬 효과, 실패·재도전, 로컬 저장 및 백업·복원 흐름 검증용 테스트
- `tests/browser.test.cjs`: Chrome 모바일 뷰포트(393px·320px)에서 NPC·의뢰·Canvas 탐험·새로고침 유지·가로 넘침 등을 확인하기 위한 테스트
- 기존 개발 단계에서 APK 빌드 및 브라우저 점검을 수행했습니다. **이 문서 업데이트만으로 0.1.4 전체 회귀 테스트나 모든 Android 실기기 검증이 완료된 것은 아닙니다.**

로직 테스트 실행에는 Node.js와 `@napi-rs/canvas`가 필요합니다. 브라우저 테스트에는 Playwright와 설치된 Chromium 실행 환경이 필요하며, 저장소의 브라우저 테스트 코드는 실행 환경에 맞는 브라우저 경로 설정이 필요합니다.

실시간 전투, 온라인 멀티플레이, 실시간 뉴스 연동, 공인 자격평가, 공식 학습효과 검증은 제공하지 않습니다. 현재는 학습 개념을 체험하는 **프로토타입**이며, 실제 수출 업무에는 최신 법령·대상 제품·지정기관의 수용 조건을 별도로 확인해야 합니다.

## 자료의 성격·개인정보·라이선스

- 게임 속 기업·사례·수치·규정 발췌·기관 협력 지수는 **교육용 가상 설정**입니다. 공식 출처 링크와 기관 관계를 도감에서 안내하나, 법령 및 표준 원문을 게임에 재배포하지 않습니다.
- 서버 계정·광고·결제·분석 SDK는 없으며 게임 기록은 기기에 보관됩니다. 사용자가 외부로 내보낸 백업 파일은 별도 관리가 필요합니다. 자세한 내용은 앱 안의 개인정보처리방침을 확인하세요.
