# 스탠다리아: 국경의 수호자

Android 오프라인 교육용 RPG 시제품 0.1.2. 해외기술규제 전문가 역량을 사례 기반 판단과 RPG 육성으로 연결합니다. 상용 RPG 완성본이나 공인 교육·자격평가 도구는 아닙니다.

## 설치와 시작

1. `Standaria-0.1.2.apk`를 Android 휴대폰에서 열어 설치합니다.
2. 설치 앱의 ‘이 출처 허용’ 안내가 나오면 해당 다운로드 앱에 설치 허용을 적용합니다.
3. ‘스탠다리아’를 열어 이름·직업·외형을 선택합니다.
4. 탐험 지도에서 길 위를 터치하거나 방향 버튼으로 이동합니다. NPC 가까이에서 ‘대화 / 조사’를 누르거나 아래 지역 의뢰를 선택합니다.
5. 자료를 펼쳐 핵심 증거 2개를 고르고, 2단계 전략을 실행합니다. 오판 시 해설을 읽고 재판단합니다.
6. 길드 레벨 상승 후 캐릭터에서 능력치와 스킬 포인트를 배분하고, 공방에서 장비를 구매·장착합니다.

Android 8.0 이상 / target API 35. 설치용 개발 서명 APK입니다. Android 앱 권한에 인터넷·전체 저장소·연락처·마이크 권한은 요구하지 않습니다. 학습 출처 링크는 외부 브라우저에서 열립니다. 파일 내보내기·가져오기는 Android 시스템 파일 선택기를 사용합니다.

## 구현된 RPG 구조

- 6개 거점, 이동 가능한 픽셀 지도, NPC, 지역 보물, 지식의 샘
- 직업 3개, 외형 3개, 레벨·경험치·골드·완료 칭호
- 규격해석·시험평가·규제분석·협상·정보분석의 5개 능력치
- 7개 장비, 3개 장착 부위, 능력치·오판 손실·경험치 효과
- 근거 통찰·리스크 방벽·정밀 분석 스킬, 집중 자원과 의뢰당 사용 제한
- 13개 연속 의뢰(최종 통합 레이드 포함), 39개 자료, 26개 전략 단계
- 핵심 증거 조사 → 전략 실행 → 해설 → 최종 보고 → 보상
- 예산·기간·신뢰 소진 시 실패 및 재도전
- 정답 전략의 대응력에 역량과 장비 적용. 능력치만으로 오판을 성공시키지 않음
- 정답·자료·전략 보기를 섞어서 제시. 완료 의뢰 복습 가능, 성장 보상 중복 지급 없음
- 가상 국제 정세 사건 3개, 사건별 전략 3개와 자원·협력 관계의 차이
- 기업·규제당국·시험기관·표준화위원회와 가상 협력지수, 임계치 달성 시 의뢰 준비 지원
- 기기 내 자동 저장, JSON 백업/복원, 텍스트 학습 보고서 내보내기
- 공식 출처 링크와 기관 관계 도감

실시간 전투, 온라인 멀티플레이, 실시간 뉴스 연동, 음성 연기, 대규모 열린 세계는 포함하지 않습니다. 실제 사례·국가별 제품 규정의 세부 적용판·시험항목을 망라하는 콘텐츠가 아니라 핵심 개념을 학습하는 첫 프로토타입입니다. 중국·한국의 세부 인증 경로와 실제 지정기관 검색은 후속 콘텐츠로 확장할 수 있습니다.

## 소스와 빌드

- 시나리오: `app/src/main/assets/content.js`
- 게임 로직: `app/src/main/assets/game.js`
- 화면과 스타일: `index.html`, `style.css`
- Android 셸·파일 선택기: `MainActivity.java`
- `build-apk.sh`: Gradle 없이 Android SDK build-tools로 직접 빌드
- Gradle 프로젝트도 제공: AGP 8.7.3 / compileSdk 35 / 별도 게임 외부 의존성 없음

직접 빌드에는 JDK 17+, Android SDK platform 35 및 build-tools 35.0.0, `zip`, `keytool`이 필요합니다.

```bash
export ANDROID_SDK_ROOT=/your/android-sdk
./build-apk.sh
```

출력: `build/Standaria-0.1.2.apk`
Android Studio에서는 프로젝트를 열고 SDK 경로를 지정해 빌드할 수 있습니다. Gradle 방식은 최초 사용 시 빌드 플러그인 다운로드가 필요합니다. 이 소스에는 Gradle wrapper는 포함하지 않습니다.

기존 릴리스용 소스 ZIP의 `build/development.jks`는 제공 APK와 동일한 개발 서명 키입니다. GitHub 저장소에는 이 키를 포함하지 않습니다. 테스트 업데이트 호환용으로 공유된 개발 키이며 상용 배포용 개인 키로 사용하면 안 됩니다. 공개 저장소에 올릴 때는 이 키를 제외하고 별도 배포 서명 체계를 정하십시오. `build/` 전체를 무시하는 `.gitignore`를 포함합니다.

브라우저에서도 assets 폴더에 정적 서버를 열면 플레이할 수 있습니다. Android 전용 파일선택 기능은 브라우저 다운로드/파일입력으로 대체됩니다.

## 검증과 제한

`tests/game.test.cjs`는 production 게임 코드의 13개 연속 의뢰, 해금, 복습 보상 제한, 장비/스킬/능력치 효과, 사건 중복 처리, 실패/재도전, 저장/복원, 학습 보고서 내보내기를 검증합니다. 테스트에는 Node.js와 `@napi-rs/canvas`가 필요합니다. `tests/browser.test.cjs`는 Playwright·Chrome으로 실제 웹 UI를 검증하며 실행파일 경로를 환경에 맞게 지정해야 합니다. 브라우저 렌더링·실기기 테스트를 대체하는 테스트는 아닙니다.

```bash
node tests/game.test.cjs
```

APK 컴파일·패키징과 v2/v3 서명 검증을 완료했습니다. Chrome 138 모바일 뷰포트에서 NPC 수락·13개 의뢰·Kontra 탐험·새로고침 후 저장 복원·393px/320px 가로 넘침을 확인했고 JavaScript 오류가 발생하지 않았습니다. Galaxy S25 / Android 16 실기기 설치·터치·외부 브라우저·파일 선택기 동작은 이 작업 환경에서 직접 확인하지 못했습니다. WebView 버전과 기기 설정에 따라 화면·파일 기능을 확인할 필요가 있습니다.

## 사용자의 진행 데이터

진행은 앱의 로컬 저장소에 기록됩니다. 앱 삭제나 앱 데이터 삭제 시 사라질 수 있으므로 설정의 백업 기능을 이용하십시오. 복원은 현재 캐릭터를 교체하므로 앱 내 확인 절차를 거칩니다. 진행 중 의뢰는 복원 시 새로 수락하며 완료 기록·장비·성장·협력 기록은 유지됩니다. 서버·계정·분석 SDK·광고·인앱 결제는 없습니다.

## 0.1.2 업데이트

상태바·디스플레이 컷아웃·시스템 내비게이션 영역만큼 WebView 자체의 레이아웃 경계를 축소했습니다. WebView 내부 패딩 대신 부모 컨테이너에서 실제 여백을 적용하여 CSS 고정 하단 메뉴가 갤럭시의 하단 시스템 버튼 영역에 겹치지 않도록 수정했습니다. 화면 키보드 표시 시에도 해당 영역을 피합니다. 패키지 ID·개발 서명·로컬 저장 키는 유지하므로 기존 앱 위에 업데이트 설치할 수 있습니다. 기존 게임 콘텐츠·보상·육성 규칙은 변경하지 않았습니다.

Git용 배포에는 서명 키와 APK를 포함하지 않습니다. 기존 릴리스용 소스 ZIP과 Git용 ZIP은 구성 목적이 다릅니다.
